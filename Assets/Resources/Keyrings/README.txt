키링 외형 FBX 모델을 이 폴더에 넣으세요. FBX 파일명이 선택 목록에 표시됩니다.

모델 원본 크기와 피벗 위치는 자동 보정됩니다. 렌더러 전체 경계를 기준으로 중심이 정렬되고, 가로·세로·깊이 중 가장 긴 축이 0.11 Unity 단위(11cm)가 되도록 비율을 유지해 크기를 통일합니다. 모델은 로컬 +Y가 위를 향하도록 제작하세요.

FBX에는 외형만 넣으면 됩니다. 은색 고리 체인과 물리는 키링 코드가 공통으로 관리합니다. FBX와 같은 이름의 PNG를 넣으면 장착할 때 모델의 기본 색 텍스처로 적용합니다. 예: Animal.fbx + Animal.png. PNG는 모델의 UV에 맞춰 입혀지므로 FBX에 UV가 있어야 합니다. PNG가 없으면 FBX의 기존 머티리얼 색을 사용합니다.

모델 목록은 커스텀 메뉴의 키링 항목을 열 때 다시 읽으므로 FBX를 추가하거나 교체한 뒤 키링 항목을 다시 열면 반영됩니다.
