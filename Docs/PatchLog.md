# 버전별 패치로그 (jungle6_w07_b2)

빌드 버전 관리 시트의 커밋을 기준으로 각 빌드에 포함된 변경점을 정리했다.
같은 커밋을 가리키는 빌드(연속 재빌드)는 변경점이 동일하므로 함께 묶었다.

---

## 0.1.1 — `7ecdd60` (develop, 2026-10-15)

초기 베이스라인. 이 빌드까지는 기능 도입 전반이 담겨 있어 주요 축만 정리한다.

- **로그/데이터 수집**: 이벤트 핸들러 기반 상점 로그 수집, 야간 습격 로그 추가, 로그 전송기·로그킷 업데이트, 로그 서버 주소를 코드에서 빼고 환경변수·`.env`로 이동
- **경제/규칙**: 스테이지 입장 코스트 추가, 야간 습격 사망 페널티 제거, 블록·적 ID 시스템 추가
- **NPC·오더**: NPC 요구조건을 HUD 우측 상단에 현재/요구 수량으로 표시, 0~8일차 NPC 요구사항 데이터 갱신, 요구조건 UI 가독성 개선
- **버그 수정**: 표적 종 저장의 재귀 직렬화로 JsonUtility 깊이 제한에 걸려 세이브를 읽지 못하던 문제, Intro 클릭 불가, 동적 TMP 폰트 에셋 무의미한 변경점 방지, NPC 사격 테스트 조건

## 참고

- 0.1.2와 0.1.3, 0.1.9~0.1.11은 같은 커밋의 재빌드이며 코드 변경은 없다.
- 시트의 0.1.7 커밋 필드는 `1.95E+30`으로 손상되어 있으며 실제 커밋은 `1945e27`이다.
- 0.1.8은 main 브랜치에서 1초 만에 실패한 빌드로 버전 라벨과 커밋이 비어 있다.
