# 0일차 튜토리얼 초안

현재 실행 데이터는 `Assets/Data/Tutorials/Day0_Tutorial.asset`이다. 이 문서는 전체 흐름을 검토하기 위한 플롯이며, 문서를 수정하면 실행 데이터에 자동 반영되는 구조는 아니다.

새 기능은 직접 해 보고, 반복되는 제작·판매는 짧은 목표만 따라가게 한다. 대화에서는 한 번에 다음 행동 하나를 안내한다. 행동 단계 동안 좌상단 목표와 전용 삼각형/화살표로 현재 대상을 표시한다. 작업대 편집 중 추적 삼각형은 숨기며, 제작 도중 밖으로 나오면 작업대 재진입을 안내한다.

## 실행 데이터 편집

- 대출 팝업 취소 뒤 다른 다이제틱 제작 UI(레시피·프리셋·이름·공유 코드)의 허용되지 않은 버튼을 누르면 다른 대상과의 F 상호작용과 동일한 튜토리얼 차단 문구를 보여 준다.
- `TutorialStep.id`: 단계 식별자. 씬 왕복 재시도는 `raid-retry` 단계로 돌아온다.
- `requiresWorkbenchEditing`은 편집 단계의 재진입 허용, `requiredRotationDegrees`는 우클릭 드래그별 누적 회전 완료 각도(45도, 360도 후 원위치도 인정), `rotationGuide`는 원 안 방향/원 밖 곡선 화살표 설정이다.
- `buttonGuide`는 레시피 열기·프리셋1·지도 목조주택·대출받기 버튼에 클릭을 통과시키는 노란 점멸 커버를 표시한다. 버튼 배경 이미지 모양·슬라이스와 크기를 자동으로 따른다. 여러 선택지에서 특정 행동을 유도할 때만 표시한다. 프리셋 저장 선택도 포함하며, 대출 외 대화 확인·일반 예/아니오·정산 확인·레시피 닫기는 강조하지 않는다. 버튼 원래 색은 수정하지 않는다. 작업대 튜토리얼의 모든 행동 목표에서 회전을 허용하고 대화 중 총기 정보는 유지한다.
- `description`은 확인 대화, `objective`는 좌상단 행동 목표, `objectiveWhileChoiceOpen`은 선택창 중 좌상단 목표, `choiceGuidance`는 대출 선택창이 열린 후 F로 확인하는 하단 튜토리얼 대화다. `target`/`targetLabel`은 추적 대상이다.
- `completion`은 확인·신호·5면 차단·특정 모듈 배치·셀 비움·현재 손님 조건 충족·작업대 퇴장·무기 장착·정산 닫기·판매 완료·손님 사격 처리 중 선택한다.
- 설치 단계의 `requiredModuleId`/`requiredCell`/`requiredOutputDirection`과 `restrictPlacement`로 요구 배치를 지정한다. `hintCells`는 노란 안내 칸이다.
- `allowedModuleIds`는 첫 작업대부터 기본만 허용하고 연장·관통·연사·방사·폭발 안내마다 허용한다. 연사는 세 번째 주문 제작 준비부터 선택 가능하고, 설치는 레시피 확인 후 순서대로 안내한다. 돌격소총을 만드는 세 번째 주문에서는 방사를 선택할 수 없으며 다음 손님부터 다시 허용한다. 폭발 선택은 습격 준비 시작부터 연다. 습격 무기 완성 이후에도 튜토리얼 선택 잠금을 유지하고, 추가 설치 시 완성된 무기를 집도록 알림을 표시한다. 실제 해금 상태는 유지한다. 연장 설치 단계에서 기본 블록 등 다른 블록은 연장 블록을 설치해 주세요 알림으로 막고, 연장 블록 위치/방향 오류는 기존 안내를 유지한다.
- 제작 선택과 `allowedActions`로 설치·삭제·회전·초기화·팔레트·퇴장·이름·프리셋·공유·레시피 등 주요 조작을 허용한다. 빈 배열은 제한 없음, `none`은 작업 조작 금지다.
- 다음 주문의 `prepareBlockedCore`는 기본 5면 몸체를 준비한다. 세 번째 주문에서는 `preparedWeaponPrefab`의 돌격소총 프리셋을 사용하고 `preparedWeaponOpenCells`의 연사 2칸·관통 1칸만 비운다. 주문 모듈은 플레이어가 직접 설치한다.
- `setBalanceOnStart`는 해당 단계 진입 때 소지금을 지정하고 그때 덜어낸 금액을 보관한다. `restoreWithheldBalanceOnComplete` 단계 완료 때 그 차액만 반환한다.
- 0일차 전용 손님은 `Assets/Data/Customers/Day0`에 있으며 `Day0.asset`에서 순서를 바꾼다. 일반 일차 손님과 분리되어 있다.

## 연습 범위

- `Tutorial_WoodenHouse`는 일반 `NightRaid_WoodenHouse`의 복사 씬이며, 별도 튜토리얼 매니저·상자 설정·적 출격 활성화·연습 플레이어 체력 무적·넉백 유지을 적용한다. 일반 목조주택 씬은 수정하지 않는다.
- 씬 왕복은 튜토리얼 단계 데이터만 메모리에 유지한다. 습격 귀환 시 출발 전 공방 스냅샷으로 복원하여 연습 해금·재료·파괴·사망 손실을 실제 진행에 반영하지 않는다.
- 제작용 임시 돈·재료는 튜토리얼 종료 때 시작 전 상태로 복구하며, 튜토리얼에서 등록한1번 프리셋은 유지한다. 마지막 연습 무기를 정리하고 1일차를 시작한다. 튜토리얼 도중 디스크 저장은 지원하지 않는다.
- 플레이 테스트는 실행하지 않았다. 시간·거리·대사 길이와 체감 난이도는 실제 플레이 후 조정 대상이다.

- 습격 상자 안내: 안내된 차지 모듈 상자 5m 이내 접근 → 스캔 설명 대화 → Q를 누른 채 해당 상자의 스캔 완료 → 성공 설명·파괴/획득/탈출 안내 → 사격으로 파괴·모듈 획득. 접근/스캔 단계는 requiredTargetDistance로 거리를 조절한다.

- 연습 상자는 스캔 성공 전 피해/파괴를 차단하며, 스캔 성공 시 보호를 해제한다. 일반 습격 상자는 보호하지 않는다.
